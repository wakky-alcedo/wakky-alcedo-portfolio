## 1. サイト概要

| 項目 | 内容 |
|------|------|
| サイト名 | Alcedo Works |
| コンセプト | ものづくり・トライアスロン・好奇心。カワセミのように、深く鮮やかに。 |
| 対象ユーザー | 作品・活動に興味を持つ人全般 |
| 言語 | 日本語（一部英語表記あり） |

### 1.1 サイトの目的

#### 目的 1 — 作品と人となりを知ってもらう

ハードウェア・IoT・AI シミュレーターなどの制作物、トライアスロン参戦記や展示会訪問記録を通じて、**作者がどんな人間で、何を作り、どう生きているか**を伝える。単なる作品紹介にとどまらず、作品の背景にある思考や姿勢まで届けることを目指す。

#### 目的 2 — サイト自体の演出で楽しんでもらう

「見たことのない体験」をサイトの演出で実現する。カワセミが川に飛び込む瞬間のような**没入感・驚き・美しさ**をインタラクションで表現し、コンテンツを見に来た人が**サイトそのものも楽しんで帰れる**ことを目指す。

> コンテンツと演出の両方が「作者らしさ」の一部である。

## 3. 演出仕様

### 3.1 トップページ — ヒーローセクション

#### 3.1.1 レイアウト構造

```
<div class="hero-fixed">   ← position: fixed; top:0; height:100dvh; z-index:10
  背景SVG（上半分=水上のみ表示）
  カワセミCanvas
  テキストブロック
  スクロールヒント
</div>
<div class="hero-spacer">  ← height: 100dvh（スクロール量を確保するスペーサー）
</div>
<div id="main-content">   ← z-index:15（hero-fixed より上）水中コンテンツ
</div>
```

- `hero-fixed` は `position: fixed` で常にビューポートに固定される
- `hero-spacer` がスクロール距離を確保する（高さ = 100dvh）
- `main-content` は `z-index: 15` でスクロールに従い hero-fixed の上を覆う
- spacer をスクロール後は `hero-fixed` を `translateY` で上方へスライドアウト
- `100dvh` を使用し iOS Safari のアドレスバーを考慮した正確なビューポート高を確保

**ビューポート最下辺 = 水面ライン**（`hero-fixed::after` でシマーアニメーションを付与）

#### 3.1.2 背景 — 時刻・季節連動シーン

背景は CSS カスタムプロパティで色変数を切り替えることで実現（ビットマップ画像の切替ではない）。

| 時間帯 | スロット名 | 夜モード |
|--------|-----------|----------|
| 5〜8時 | `morning` | ❌ |
| 8〜17時 | `day` | ❌ |
| 17〜21時 | `sunset` | ❌ |
| その他（夜間） | `night` | ✅（暗幕＋星） |

| 月 | 季節 |
|----|------|
| 2〜4月 | spring（桜吹雪パーティクル） |
| 5〜7月 | summer |
| 8〜10月 | autumn（落ち葉パーティクル） |
| 11〜1月 | winter（雪パーティクル） |

- 背景は `hero-scene.svg`（CSS変数で色制御）。高さ `200dvh` で配置し、上半分（水上部分）のみ `overflow: hidden` で表示
- 夜モード: 星（約90個）をキャンバスに描画。個別にきらめきアニメーション
- 季節パーティクルはアニメーションレベル3（高スペック端末）のみ表示
- 天気APIとの連携は行わない（負荷・依存性の排除のため）
- 60秒ごとに再評価（長時間閲覧での時刻変化に対応）

#### 3.1.3 カワセミの飛び込み演出

| トリガー | 動作 |
|---------|------|
| scroll 15% 到達（ワンショット） | `flyAway()` が自動発火。カワセミが飛び立ち数秒後に帰還 |
| クリック | 同上（`bird.state === 'perched'` のときのみ有効） |
| 30〜60秒放置 | 自動飛び立ち→帰還（自動フライ） |

> **廃止:** スクロール量に連動した段階的ダイブアニメーション（旧仕様の 0-8% 枝止まり → 8-55% 急降下）は廃止。即座に水中コンテンツへスクロールできることを優先。

- カワセミは常に止まり木に止まった状態（ボブアニメーション）が基本
- `flyAway` → 左方向に飛び去り → 数秒後に右から帰還 → perch に戻る
- 一定確率（30%）でカワセミが魚を咥えて帰還（FishCatch モジュール）

#### 3.1.4 波紋・水しぶきエフェクト

`flyAway` 発火時などの演出用として実装（on-demand）：
- 水面突入時に波紋を6個生成（ランダム位置にずれ）
- 水しぶきパーティクルを25個生成（上方向に飛散し重力落下・フェードアウト）
- 波紋は楕円形（水面の遠近感を表現）

#### 3.1.5 テキストブロック・UIのフェード

`heroProgress() = scrollY / innerHeight`（0〜1）に連動：

| 要素 | 動作 |
|------|------|
| タイトル・バッジブロック | p=0→33%でフェードアウト |
| 「SCROLL TO DIVE」ヒント | p=0→20%で消える |
| 「クリックで飛び立つ」ヒント | p>5% で非表示 |

### 3.2 トップページ — 水中セクション

`#main-content`（`z-index: 15`）。スクロールに従い水面下から浮上してくるように見える。

#### 3.2.1 背景・光線演出

- 深海グラデーション背景（`#0a1e30 → #040f1a`）
- 水面からの光線アニメーション（`.uw-light-rays`）: 6本の光線が揺らめく

#### 3.2.2 魚・泡アニメーション（Canvas）

- 魚: ランダムに泳ぐ。カーソルに近づくと逃げる（**トップページのみ**）
- 泡: 水底から浮上するバブルアニメーション
- IntersectionObserver で `#main-content` が画面内に入ったときのみ RAF ループを起動（パフォーマンス最適化）

#### 3.2.3 デバイス傾き（隠し要素）

- フッターのトグルで有効化
- スマートフォンを傾けると魚の重力方向が変わる
- `DeviceOrientationEvent` を使用

### 3.3 トップページ — コンテンツセクション

`main-content` 内に縦に並ぶ。

#### 3.3.1 Portfolio セクション

- 最新作品を **3点**（`featured: true`）プレビュー表示（グリッド）
- 各カード: サムネイル / カテゴリタグ / タイトル / 概要文
- 「すべての作品を見る →」リンクで `portfolio/index.html` へ

#### 3.3.2 Blog セクション

- 最新記事を **3件**（日付降順）プレビュー表示（縦リスト）
- 各エントリ: 日付 / カテゴリタグ / タイトル / 概要文
- 「すべての記事を見る →」リンクで `blog/index.html` へ

#### 3.3.3 About セクション

- `content/about.md` を marked.js でレンダリング
- 将来ボリュームが増えた場合は独立ページ（`about.html`）に分離

#### 3.3.4 Contact セクション

- `content/contact.md` を marked.js でレンダリング
- 詳細は `contact.html` へリンク

### 3.4 各記事ページの演出

#### 3.4.1 タイトル部のカワセミ（ダイブ演出）

- 記事タイトル付近にカワセミが止まり木に止まっている
- スクロール開始と同時に勢いよく水中へ飛び込む（= ここから記事コンテンツが始まるメタファー）

#### 3.4.2 フッター部のカワセミ（止まり木演出）

- 記事最下部（コメント欄・関連記事リンクエリア）で、魚を咥えて満足そうに止まり木に止まっている

> **廃止:** 記事ページでのカワセミスクロールバー。モダンブラウザの標準スクロールバーで十分なため。

#### 3.4.3 記事コンテンツ内演出（記事ごとのカスタム）

記事の内容に応じてセクション単位で演出を追加できる。例：
- トライアスロン参戦記のスイムセクション → 水中演出
- バイクセクション → 風を感じる演出

#### 3.4.4 ギミック限定化

- **魚がカーソルを逃げるギミックはトップページのみ**
- 記事本文中では入れない（コンテンツへの集中を優先）

---

### 3.5 Portfolio ページ

- 全作品をカード形式で一覧表示（グリッドレイアウト）
- 各カード: カテゴリタグ / タイトル / 説明文 / サムネイル
- カードホバー: 浮き上がり + ボーダー発光
- カテゴリフィルター（将来対応）

### 3.6 Blog ページ

- 全記事をタイムライン形式（縦並び）で一覧表示
- 各エントリ: 日付 / カテゴリタグ / タイトル / 冒頭文

### 3.7 Contact ページ

- 連絡手段を一覧で掲載
- フォームなし（静的サイトのため）

### 3.8 共通演出

- カードホバー: `translateY(-4px)` + ブルーボーダー + グロー
- ページ内リンク: スムーススクロール
- ナビロゴにカワセミアイコン（SVG）

## 4. 技術仕様

### 4.1 技術スタック

| 項目 | 採用技術 |
|------|---------|
| マークアップ | HTML5 |
| スタイル | CSS3（カスタムプロパティ / Flexbox / Grid） |
| スクリプト | Vanilla JavaScript（ES2020） |
| アニメーション | Canvas API（ヒーロー・水中演出）/ CSS アニメーション（UI） |
| Markdown レンダリング | marked.js（CDN） |
| フレームワーク | **なし**（静的サイト） |
| ビルドツール | **なし** |

### 4.1.1 コンテンツ管理フロー

```
[執筆]                 [公開]
content/*.md  →  marked.js がブラウザ上でHTMLに変換  →  表示
```

- コンテンツはすべて `content/` フォルダ内の `.md` ファイルに書く
- 記事追加時は `data/portfolio.json` または `data/blog.json` に1行追加するだけ

### 4.2 ファイル構成

### 4.4 ホスティング要件

- レンタルサーバー or 自宅サーバー、静的ファイル配信のみ（PHP/DB 不要）
- HTTPS 推奨

### 4.5 対応ブラウザ

| ブラウザ | 対応方針 |
|---------|---------|
| Chrome / Edge（最新） | ◎ 完全対応 |
| Firefox（最新） | ◎ 完全対応 |
| Safari（最新） | ◎ 完全対応（`100dvh` 使用で iOS Safari 対応） |
| モバイル（iOS Safari / Android Chrome） | ○ 対応（タッチ・傾き操作対応） |
| IE11 以下 | ✕ 対応外 |

### 4.6 パフォーマンス目標

| 指標 | 目標値 |
|------|-------|
| 初回表示（LCP） | 3秒以内 |
| アニメーション | 60fps（`requestAnimationFrame` ループ） |
| 背景アセット | `hero-scene.svg`（CSS変数制御）で軽量化 |

#### パフォーマンスバジェット（アニメーション段階制御）

| レベル | 条件 | 動作 |
|--------|------|------|
| 0 | `prefers-reduced-motion: reduce` | アニメーション最小化 |
| 1 | `hardwareConcurrency <= 2` | 魚・泡のみ（シンプル） |
| 2 | モバイル端末 | 標準（季節パーティクルなし） |
| 3 | 高スペック端末 | フル（季節パーティクル含む） |

- 水中アニメーションは `IntersectionObserver` で `#main-content` が非表示のとき RAF を停止
- 演出スクリプト（`underwater.js`）はコンテンツ読み込み後に実行（初期ロードへの影響を最小化）
