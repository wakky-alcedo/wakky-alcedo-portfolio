## 1. サイト概要

| 項目 | 内容 |
|------|------|
| サイト名 | Alcedo Works |
| コンセプト | ものづくり・トライアスロン・好奇心。カワセミのように、深く鮮やかに。 |
| 対象ユーザー | 作品・活動に興味を持つ人全般 |
| 言語 | 日本語（一部英語表記あり） |

### 1.1 サイトの目的

本サイトは以下の **2 つの目的** を持つ。

#### 目的 1 — 作品と人となりを知ってもらう

ハードウェア・IoT・AI シミュレーターなどの制作物、トライアスロン参戦記や展示会訪問記録を通じて、  
**作者がどんな人間で、何を作り、どう生きているか** を伝える。

単なる作品紹介にとどまらず、作品の背景にある思考や姿勢まで届けることを目指す。

#### 目的 2 — サイト自体の演出で楽しんでもらう

「見たことのない体験」をサイトの演出で実現する。  
カワセミが川に飛び込む瞬間のような **没入感・驚き・美しさ** をインタラクションで表現し、  
コンテンツを見に来た人が **サイトそのものも楽しんで帰れる** ことを目指す。

> コンテンツと演出の両方が「作者らしさ」の一部である。

## 3. 演出仕様

### 3.1 トップページ — ヒーローセクション

#### 3.1.1 背景 — 時刻連動シーン

| 時間帯 | 背景画像 | 夜モード |
|--------|----------|----------|
| 0〜5時 | `bg_sunset.png` | ✅（暗幕＋星） |
| 5〜8時 | `bg_morning.png` | ❌ |
| 8〜17時 | `bg_day.png` | ❌ |
| 17〜21時 | `bg_sunset.png` | ❌ |
| 21〜24時 | `bg_sunset.png` | ✅（暗幕＋星） |

- 背景切替はクロスフェード（transition: 2.5s）
- 夜モード時はキャンバス上に星を描画（約90個、個別にきらめきアニメーション）

#### 3.1.2 スクロール演出 — カワセミの飛び込み

**スクロール範囲:** ヒーローセクション内（`0vh` 〜 `100vh` 分のスクロール）  
**仕組み:** スクロール量をそのまま背景とカワセミの位置に反映（アニメーション再生ではなくスクロール連動）

**背景パララックス:**
- 背景画像は `高さ200vh` で配置（上半分=水上 / 下半分=水中）
- スクロール量 `Y px` に対して画像を `translateY(-Y px)` でシフト
- スクロール `0→100vh` の間に、水面がビューポートの下端から上端へ移動

**カワセミの動き（スクロール連動）:**

| スクロール進行 (p) | カワセミの状態 |
|-------------------|---------------|
| 0 〜 8% | 枝に止まってゆらゆら（ボブアニメーション） |
| 8 〜 55% | 急降下開始。前傾姿勢に変化（角度 0°→85°）、水面に向かって加速 |
| 55% | 水面突入。水しぶきエフェクト＋波紋エフェクト |
| 55 〜 62% | 水面下へ消えていく |
| 62% 以降 | カワセミ非表示。完全に水中シーン |

**インタラクション（スクロール以外）:**
- **クリック**（スクロール量 5% 以下のときのみ有効）: カワセミが飛び立ち、数秒後に戻ってくる
- **自動飛び立ち**: 30〜60秒ランダム間隔で飛び立ち→帰還

#### 3.1.3 波紋・水しぶきエフェクト

- 水面突入時に波紋を 6 個生成（ランダムな位置にずれ）
- 水しぶきパーティクルを 25 個生成（上方向に飛び散り、重力で落下、フェードアウト）
- 波紋は楕円形（水面の遠近感を表現）

#### 3.1.4 テキストブロック・UIのフェード

| 要素 | 動作 |
|------|------|
| タイトル・バッジブロック | スクロール開始とともにフェードアウト（p=0→33%で完全消滅） |
| 「SCROLL TO DIVE」ヒント | スクロール開始直後に消える（p=0→20%） |
| 「クリックで飛び立つ」ヒント | p>5% で非表示 |

### 3.2 トップページ — コンテンツセクション

ヒーロー（飛び込み演出）の直下から、以下のセクションを縦に並べる。  
トップページ単体で主要コンテンツをひと通り閲覧できる **1ページ完結型** の構成とする。

#### 3.2.1 Portfolio セクション

- 最新作品を **3点** プレビュー表示（グリッド or 横並び）
- 各プレビューに: サムネイル画像 / カテゴリタグ / タイトル / 1〜2行の概要文
- 「すべての作品を見る →」リンクで `portfolio/index.html` へ
- 画像がない場合はカテゴリアイコンで代替

#### 3.2.2 Blog セクション

- 最新記事を **3件** プレビュー表示（縦リスト or カード）
- 各プレビューに: サムネイル画像（あれば）/ カテゴリタグ / 日付 / タイトル / 冒頭1〜2行
- 「すべての記事を見る →」リンクで `blog/index.html` へ

#### 3.2.3 About セクション

- **当面はトップページに全文を直接記載**（独立ページに移行するほど長くなるまで）
- 構成案:
  - 自己紹介文（数段落）
  - カワセミとの出会い・サイトのテーマについて
  - 使用機材・ツールなど（任意）
- 独立ページ（`about.html`）は現時点ではトップのアンカーリンクにリダイレクト

#### 3.2.4 Contact セクション

- トップページ最下部に配置
- SNS / メールアドレス / その他連絡先へのリンクをシンプルに並べる
- 詳細は `contact.html` へリンク

---

### 3.3 Portfolio ページ

- 全作品をカード形式で一覧表示（グリッドレイアウト）
- 各カードにカテゴリタグ・タイトル・短い説明文・サムネイル
- カードホバー: 浮き上がり＋ボーダー発光
- カテゴリフィルター（将来対応）
- カテゴリ例: 文化祭企画系 / IoT系 / AI Simulator / など

- 全記事をタイムライン形式（縦並び）で一覧表示
- 各エントリに日付・カテゴリタグ・タイトル・冒頭文
- カテゴリ例: トライアスロン / 展示会 / 日記 など

### 3.5 Contact ページ

- 連絡手段を一覧で掲載
- フォームは設置しない（静的サイトのため）
- 掲載予定の連絡先: （TBD — SNS / メール など）

### 3.6 共通演出

- カードホバー: `translateY(-4px)` + ブルーボーダー + グロー

- ナビロゴにカワセミアイコン（SVG）

## 4. 技術仕様

### 4.1 技術スタック

| 項目 | 採用技術 |
|------|---------|
| マークアップ | HTML5 |
| スタイル | CSS3（カスタムプロパティ・Flexbox・Grid） |
| スクリプト | Vanilla JavaScript（ES2020） |
| アニメーション | Canvas API（ヒーロー演出） / CSS アニメーション（UI） |
| Markdownレンダリング | marked.js（CDN） |
| フレームワーク | **なし**（静的サイト） |
| ビルドツール | **なし** |

### 4.1.1 コンテンツ管理フロー（Markdown運用）

```
[執筆]                 [公開]
content/*.md  →  marked.js がブラウザ上でHTMLに変換  →  表示
```

- コンテンツはすべて `content/` フォルダ内の `.md` ファイルに書く
- HTMLを直接編集する必要はない
- 記事追加時は `data/portfolio.json` または `data/blog.json` にメタ情報（タイトル・日付など）を1行追加するだけ
- **AIによる支援:** Markdownの下書きを見せることで、フォーマット整形・推敲・HTML変換を依頼できる

### 4.2 ファイル構成


### 4.4 ホスティング要件

- **サーバー種別:** レンタルサーバー または 自宅サーバー
- **配信形式:** 静的ファイル（PHP/DB 不要）
- **HTTPS:** 推奨（Let's Encrypt 等）
- **必要機能:** HTML/CSS/JS の静的ファイル配信のみ

### 4.5 対応ブラウザ

| ブラウザ | 対応方針 |
|---------|---------|
| Chrome / Edge (最新) | ◎ 完全対応（主要ターゲット） |
| Firefox (最新) | ◎ 完全対応 |
| Safari (最新) | ◎ 完全対応 |
| モバイル (iOS Safari / Android Chrome) | ○ 対応（タッチ操作対応） |
| IE11 以下 | ✕ 対応外 |

### 4.6 パフォーマンス目標

| 指標 | 目標値 |
|------|-------|
| 初回表示 (LCP) | 3秒以内 |
| 背景画像サイズ | 各 1MB 以下推奨（現状 1.6MB、要圧縮） |
| アニメーション | 60fps（requestAnimationFrame ループ） |
