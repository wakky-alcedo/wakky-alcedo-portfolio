# IoTセンサーネットワーク

## 概要

学内の各部屋にRaspberry Piベースのセンサーノードを設置し、環境データを収集・可視化するシステムを構築しました。

## 使用技術

- Raspberry Pi 4
- Python / MQTT
- InfluxDB + Grafana

## 成果

20台以上のセンサーノードを展開し、リアルタイムダッシュボードを実現。
